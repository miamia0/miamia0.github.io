# 背景

在过去的十年中，基于图的 ANNS 算法已经成为这一领域的主导范式，有数十种基于图的 ANNS 算法被提出。这些算法旨在为给定的查询提供有效、高效的最近邻检索解决方案。然而，这些努力主要集中在开发和优化采用不同方法的算法。本文基于论文 [A Comprehensive Survey and Experimental Comparison of Graph-Based Approximate Nearest Neighbor Search](https://www.vldb.org/pvldb/vol14/p1964-wang.pdf)，对基于 Graph 的向量检索方案进行综述。

# 图索引结构

| 图索引结构 | 定义 | 性质 |
| --- | --- | --- |
| DG | Delaunay Graph，基于 Delaunay 三角剖分。Delaunay 图满足以下条件：<br><br>**空圆特性**：任何一个三角形的外接圆内不包含点集 P 中的任何其他点。对于图 G(V, E) 中的每条边 e，其对应的两个顶点 x 和 y，存在一个圆通过 x 和 y，并且该圆内没有其他顶点。这意味着圆的边界上只有 x 和 y 两个顶点；圆上最多有三个顶点。 | **最大化最小角**：在所有可能的三角剖分中，Delaunay 三角剖分使得三角形的最小角最大化。 |
| RNG | 相对邻域图（Relative Neighborhood Graph, RNG）的核心思想是：如果两个点在彼此的邻域内没有更近的点，那么它们之间应该有一条边。对于图 G(V, E) 中的顶点 x 和 y，如果它们通过边 e 连接，那么对于所有其他顶点 z，满足 δ(x, y) < δ(x, z) 或 δ(x, y) < δ(z, y)。换句话说，z 不在对应的月牙形区域内。 | 与 Delaunay 图相比，RNG 去除了一些冗余邻居，使得剩余邻居在空间中分布更均匀，从而减少近似最近邻搜索中的距离计算。 |
| KNNG | K-最近邻图（K-Nearest Neighbor Graph, KNNG）中，每一个点都与它在点集中最近的 K 个点相连接。 | **有向图性质**：如果 x 是 y 的最近 2 个点之一，但 y 不是 x 的最近 2 个点之一，那么 KNNG 就是有向图。KNNG 限制了每个顶点的邻居数量上限为 K，从而避免邻居数量激增，在内存有限和高效率场景中表现较好。<br><br>**全局连通性问题**：KNNG 并不保证全局连通性，这可能不利于 ANNS。 |
| MST | 最小生成树（Minimum Spanning Tree, MST）是图论中的一个重要概念，指在连通图中找到一棵包含所有顶点的树，且总边权和最小。<br><br>具体定义如下：<br>- 给定一个连通图 G(V, E)，其中每条边 e_i 有一个权重 w(e_i)。<br>- MST 是 G 的一个子图 T，T 是一棵树，并且包含所有顶点 V。<br>- T 的总边权和最小。 | 优势在于它使用最少的边确保图的全局连通性，从而保持顶点低度数，并保证任意两个顶点可达。缺点是缺乏捷径，在 MST 上搜索时可能会绕路。 |

# 算法分类

| 索引图类型 | 算法 | 索引建立 | 搜索方法 | 相关材料 |
| --- | --- | --- | --- | --- |
| DG-based / RNG-based | NSW | 每次插入一个新的顶点时，查找距离该顶点最近的 k 个顶点，并分别连边，最终建立一个近似 DG 图。 | 贪心搜索：从图中任意一个点出发，逐步遍历到更接近目标的顶点。 | - |
| DG-based / RNG-based | HNSW | 多层 NSW，层次之间的关系类似跳表。插入点时通过随机数决定结点出现的最高层。 | 从顶层固定入口开始搜索；每层返回 Top-K 结果，并用当前层最接近查询的点作为下一层入口。最后一层的 Top-K 作为最终结果。 | - |
| DG-based / RNG-based | FANNG | FANNG 的思想是削减图上边的数量，因此定义了遮挡规则：<br>- 如果图中有从 p1 到 p2 的边，那么不需要有从 p1 到任何比 p2 更接近 p1 的顶点 p3 的边。<br>- 在这种情况下，从 p1 到 p2 的边遮挡了从 p1 到 p3 的边。<br><br>计算过程：对每一个点 Pi，将其他点按距离从小到大排序。对于每一个候选 Pu，如果当前已加入图中的 Pi 邻居集合里不存在某个 Pv，满足 distance(Pu, Pv) < distance(Pi, Pu)，则将 (Pi, Pu) 加入索引图。 | 与 NSW 类似。从图中随机选择起始点，沿着图中最近邻居进行搜索，直到找到目标点的近似最近邻。为了提高精度，FANNG 还引入回溯机制。 | paper |
| DG-based / RNG-based | NGT | 两种构建方法：<br>1. 将 KNNG 转换为双向 KNNG（BKNNG）。<br>2. 类似 NSW 的增量构建方法。<br><br>这两种方法都可能让某些中心顶点具有较高出度，因此 NGT 使用了三种度调整方法。 | 非纯贪心，带有启发式：取消候选集大小限制，并将 δ(y_hat, q) 作为搜索半径 r。对于任意 n 属于 N(x_hat)，如果 δ(n, q) < (1 + epsilon) * r，则将 n 加入候选集 C。 | <https://github.com/yahoojapan/NGT> |
| KNNG-based | SPTAG | 采用分治（divide and conquer）思想构建 KNNG，更详细内容需要回看原始论文。 | 带有启发式搜索；当某次迭代陷入局部最优时，从 KD-Tree 中选择新种子重新启动搜索。 | - |
| KNNG-based | KGraph | 思想：如果两个节点是彼此的邻居，那么它们更有可能通过其他共同邻居相互连接。<br><br>构建过程：使用 NN-Descent 算法构建近似 KNNG：<br>- 初始化邻居集合：对每个点随机选择一些点作为初始邻居。<br>- 迭代更新邻居集合：遍历当前邻居及其邻居集合，如果某个点 r 比当前集合中的一些点更接近 p，则将 r 加入并移除更远的点。 | 贪心搜索。 | - |
| KNNG-based | EFANNA | EFANNA 在构建过程中不使用随机初始化。首先在数据集上构建多个 KD-Trees，通过这些 KD-Trees 上的 ANNS 为每个顶点找到更好的初始邻居；之后的构建过程与 KGraph 类似。 | 初始化顶点从 KD-Tree 中获取，之后的检索方法和 KGraph 类似。 | - |
| KNNG-based / RNG-based | DPG | 一些论文指出，使用 KNNG 会导致访问顶点的邻居彼此过近，搜索时会遍历到相同位置，因此有些邻居是冗余的。DPG 希望通过优化邻居分布来提高图构建效率，它通过设置邻居之间的角度阈值，使邻居在顶点的各个方向上均匀分布。 | 贪心搜索。 | <https://arxiv.org/pdf/1610.02455> |
| KNNG-based / RNG-based | NSG | NSG 的思想是保证搜索过程中的路径尽量单调。MRNG 是一种单调相对邻域图，但构建复杂度过高，因此 NSG 设计了近似 MRNG 算法来加速索引构建：<br>- 构建一个近似 KNN 图。<br>- 找到数据集的近似中心点作为导航点。<br>- 对每一个点 p，生成候选邻居集合，并从中选择最终邻居。<br>- 将生成的图以导航点为根展开成 DFS 树；若仍有点未连通，则把该点连接到其近似最近邻后继续 DFS。 | 贪心搜索。 | - |
| KNNG-based / RNG-based | NSSG | 对比 NSG，NSSG 不仅考虑顶点的直接邻居，还考虑这些邻居的邻居来构建索引图。 | 贪心搜索。 | - |
| KNNG-based / RNG-based | Vamana | 初始化时，图中每个点有 R 个随机出边邻居，s 是数据集中心。之后按随机顺序迭代每个点 p：<br>- 从 s 开始对 p 进行贪婪搜索，记录路径上遇到的点集 V。<br>- 以点集 V 作为候选集，重新选择 p 的 R 个邻居，并双向连接。<br>- 如果邻居出度超过 R，则重新裁剪出度邻居。<br><br>迭代执行两次，一次 alpha = 1，一次 alpha > 1。 | 贪心搜索。 | - |
| MST-based | HCNNG | HCNNG 通过多个层次聚类将点集划分，并且在每个聚类中的所有点都通过 MST 连接。 | 使用 KD-Tree 获取 seed 点，采用启发式搜索而不是完全贪心搜索。 | - |

# 算法分析

| 阶段 | 子阶段 | 分类 | 说明 |
| --- | --- | --- | --- |
| 索引构建 | 初始化 | 分治法（divide and conquer） | 分治法先对数据集进行划分，通过递归生成多个子图，然后通过子图合并获得结果。SPTAG 采用随机划分方案，HCNNG 通过迭代层次聚类进行划分。 |
| 索引构建 | 初始化 | 精炼法（refinement） | 对每一个点的邻居进行初始化，获取初始图，然后通过精炼迭代提高搜索性能。KGraph 和 Vamana 通过随机邻居初始化；EFANNA 通过多个 KD-Tree 获取更好的初始邻居；NSG、DPG 和 NSSG 使用 NN-Descent；FANNG 和 IEH 通过全量扫描初始化邻居。 |
| 索引构建 | 初始化 | 增量法（incremental） | 从索引 G(V, E) 中获取小子集作为种子集。NSW 和 NGT 随机获取种子，HNSW 则从顶层固定种子点开始。 |
| 索引构建 | 候选邻居选取 | 分治法 | 通常从数据集划分后得到的小子集中获取候选邻居，复杂度较低。 |
| 索引构建 | 候选邻居选取 | 精炼法 / 增量法 | 不涉及数据集划分，IEH 和 FANNG 采用全量扫描获取候选邻居，效率较低。NGT、NSW、HNSW、NSG 和 Vamana 则通过 ANNS 获取候选邻居。 |
| 索引构建 | 邻居选择 | 考虑距离因素 | NSW、SPTAG、NGT、KGraph、EFANNA 和 IEH 仅考虑距离因素，选取最近的 k 个邻居。 |
| 索引构建 | 邻居选择 | 考虑空间因素 | HNSW、FANNG、SPTAG 和 NSG 通过评估邻居之间的距离来考虑空间分布，使邻居在 p 的各个方向上尽可能均匀。 |
| 索引构建 | 邻居选择 | 其他 | Vamana 通过参数 alpha 更灵活地控制邻居选择；DPG 通过获取候选集子集最小化任意两点之间的角度和；NSSG 通过角度阈值控制；NGT 通过路径调整间接实现均匀分布；HCNNG 通过在 {p} 并 C 上构建 MST 来选择邻居。 |
| 索引构建 | 种子预处理 | 静态方法 | HNSW 将顶层顶点固定为种子；NSG 和 Vamana 使用近似质心作为种子；NSSG 使用随机顶点。 |
| 索引构建 | 种子预处理 | 动态方法 | 常见做法是附加其他索引。SPTAG、EFANNA、HCNNG 和 NGT 会构建额外的树，如 KD-Tree、平衡 k-means 树和 VP-Tree；IEH 通过哈希准备种子。 |
| 索引构建 | 种子预处理 | 随机选择 | KGraph、FANNG、NSW 和 DPG 采用随机种子获取，不需要实现额外种子预处理。 |
| 索引构建 | 连通性 | 分治法 / 增量法 / 精炼法 | 分治法通过合并过程保证连通；增量法在插入过程中逐步连通；精炼法通常通过 DFS 保持连通。 |
| 搜索 | 种子获取 | 随机 / 固定种子 | 搜索的起点可能来自随机选择，也可能来自预处理阶段生成的固定种子。 |
| 搜索 | 路由 | 贪心 BFS | NSW、HNSW、KGraph、IEH、EFANNA、DPG、NSG、NSSG 和 Vamana 使用原始贪心 BFS 进行路由。这种方法直接，但容易陷入局部最优，且效率偏低。 |
| 搜索 | 路由 | 优化方法 | FANNG 通过在 BFS 中加入回溯提高精度，但显著增加搜索时间；NGT 通过参数 epsilon 缓解局部最优问题；SPTAG 通过多次 BFS 和重新选种子缓解局部最优；HCNNG 通过引导搜索减少冗余访问。 |

# 问题记录

## 为什么并没有流式更新

参考 NSG 作者的相关文章，向量召回索引可能是一个伪命题。向量并不代表真正的原始数据，而是通过算法模型计算出的降维表征。在模型更新后，所有数据都需要重新计算。在一段较短的时间内，可以使用 SPFresh 让系统维持一个不错的性能；但长期来看，重建索引仍然是一个必然选择。

## 基于磁盘的图索引算法

1. 既然内存有限，那么可以先通过 KMeans 将原始数据集粗略分成 k 个簇。对于每一个特征向量，都将它放到离它最近的 i 个簇中，通常 i = 2。然后对每个簇建立图索引，最后再合并全部结果。
2. 通过原始向量建立 index，而在查询过程中使用压缩向量。为了确保图索引质量，可以使用原始向量完成建图；尽管检索过程中使用压缩向量会带来一定精度损失，但在生成最终 NN 结果时仍可回到原始特征向量进行精排，从而减少精度损失。
